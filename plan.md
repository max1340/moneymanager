# Financy PRO — Plan v2.1 (UI/UX Рефакторинг 10 пунктов)

## Статус: 🚀 Все 10 пунктов UI/UX полностью реализованы, протестированы и собраны

## Список задач по пунктам:

- [x] **1. Период**:
  - Опции селектора периодов обновлены в явный формат: `Цикл: 10.08–09.09 (Август 2026)`.
  - Подпись текущего периода (`.period-pill`) добавлена рядом с итогами в журнале операций и на обзорных карточках («Свободный бюджет», «Баланс»).
  - Добавлены хелперы `cycleShortRange` и `cycleExplicitLabel` в `utils.js`.

- [x] **2. Шапка (Header)**:
  - Зеленый индикатор синхронизации дополнен всплывающим тултипом «Сохранено в облаке» и атрибутом `title`.
  - Всем иконочным кнопкам в шапке (селектор периода, кнопка меню «⋮», закрытие модалок) прописаны явные `aria-label` и `title`.
  - Оптимизирована адаптивность шапки (`flex-shrink`, минимальные отступы), исключено наложение элементов на узких экранах (320–375px).

- [x] **3. Форма добавления**:
  - Поле ввода даты: текстовый инпут с маской `ДД.ММ.ГГГГ` (`inputmode="numeric"`) + кнопка календаря для вызова нативного пикера (`showPicker()`) с двусторонней синхронизацией.
  - При выборе сегмента «Доход» подпись поля категории динамически меняется на «Категория дохода», а список категорий обновляется (Зарплата, Подработка, Возврат, Инвестиции, Подарок, Прочее).
  - Кнопка «Скопировать постоянные»: добавлен тултип с описанием действия, а после нажатия выводится тост «Добавлено N операций — Отменить» с рабочей отменой добавленных операций (`undoTemplate`).

- [x] **4. Журнал операций**:
  - Тап по строке операции открывает Bottom Sheet (на мобильных) / модальное окно с подробностями и кнопками «Редактировать» и «Удалить».
  - При удалении операции показывается тост обратной связи с кнопкой «Отменить» (Undo), восстанавливающей запись.
  - Добавлена группировка операций по дням с разделителями («Сегодня, 15 авг», «Вчера, 14 авг», «10 авг») и суммой за день (`+200 ₪ / -50 ₪`).
  - Чипы фильтров («Все / Доходы / Расходы») и сводка периода зафиксированы (`sticky`) вверху списка.

- [x] **5. Валюта**:
  - Символ валюты вынесен в единую константу `export const CURRENCY = '₪'`.
  - Создана функция `export function fmt(amount)` (с псевдонимом `formatMoney = fmt`).
  - Функция и константа применены во всех модулях: `app.js`, `charts.js`, `crud.js`, `utils.js`.

- [x] **6. Цели**:
  - Кнопка «Пополнить» на каждой карточке цели открывает форму быстрого внесения средств.
  - Меню «Редактировать / Удалить» на карточке цели с отдельными модальными окнами.
  - Добавлен расчёт и отображение срока цели (дата) и подсказки: «Нужно откладывать X ₪ в месяц, чтобы успеть».
  - Плавающая кнопка FAB на вкладке «Цели» открывает форму создания цели, а на вкладке «Настройки» автоматически скрывается.

- [x] **7. Настройки**:
  - Список регулярных (постоянных) транзакций дополнен отображением сумм и тумблером-переключателем «добавлять автоматически каждый цикл» (`toggleRecurringAuto`).

- [x] **8. Доступность и инпуты**:
  - Для всех числовых инпутов (суммы, проценты) установлен атрибут `inputmode="decimal"`.
  - Контрастность вторичного текста проверена и гарантирована на уровне ≥ 4.5:1 (в светлой теме `#64748b` по `#f8fafc` дает > 5.5:1).
  - Все иконки и кнопки без текста снабжены `aria-label`.

- [x] **9. PWA и бэкапы**:
  - Созданы и настроены `manifest.json` и Service Worker `sw.js` (кэширование статики, работа оффлайн).
  - Экспорт бэкапа сохраняет файл с текущей датой: `financy_backup_YYYY-MM-DD.json`.
  - Реализовано напоминание о бэкапе: если экспорт не производился более 7 дней, на кнопке меню «⋮» отображается красный индикатор-точка и предупреждающий бейдж в выпадающем меню.

- [x] **10. Десктопная версия (≥768px)**:
  - Вкладка «Обзор»: карточки организованы в 2 колонки (`grid-template-columns: repeat(2, 1fr)`).
  - Вкладка «Операции»: двухколоночная раскладка — форма добавления зафиксирована слева (380px), журнал операций расположен справа с независимым скроллом.
