# Выявленные проблемы и статус (issues.md)

## 1. Firebase Realtime Database Security Rules
- **Проблема**: По умолчанию чтение/запись в новую ветку `financy` в базе данных Firebase могут быть заблокированы правилами безопасности (отказ в доступе `Permission denied`).
- **Решение**: В консоли Firebase (Database -> Rules) необходимо добавить правило доступа для `financy`:
  ```json
  "financy": {
    ".read": true,
    ".write": true
  }
  ```
- **Статус**: Ожидает добавления в Firebase Console.

## 2. PWA Service Worker на localhost vs HTTPS
- **Проблема**: Service Worker и установка PWA в браузерах работают только через HTTPS (либо на localhost).
- **Решение**: При деплое на Netlify HTTPS включается автоматически «из коробки», PWA будет регистрироваться и работать штатно.
- **Статус**: Решено архитектурно.

## 3. Защита конфиденциальных локальных файлов в репозитории
- **Проблема**: Локальный файл `financy_db.json` с персональными финансовыми данными мог случайно попасть в публичный Git-репозиторий.
- **Решение**: Файлы `financy_db.json`, `financy_backup_*.json` и `financy_export_*.csv` добавлены в `.gitignore`.
- **Статус**: Решено.
